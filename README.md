# BeatBreeze
### Description
Beat Breeze merupakan aplikasi pencarian musik berbasis web yang dapat digunakan untuk membantu user mencari lagu yang sesuai dengan 'mood' yang sedang dirasakan. Aplikasi ini menggunakan Deezer API untuk mengintegrasikan database lagu ke aplikasinya.
### Contributions
Projek web ini merupakan hasil kolaborasi tim dengan mahasiswa lain, yang dibuat untuk memenuhi kriteria kelulusan matakuliah HCI (Human-Computer Interaction). Kontribusi saya pada projek ini mencakupi:
